# Cinna Travel Archive

English | [简体中文](./README.zh-CN.md)

Source for an earlier Cinna Travel guide to a Tibet road trip.

[Current Cinna Travel project](https://github.com/icelemon233/cinna-travel)

The guide includes daily plans, route options, preparation steps, risk tables, budgets, and maps. Its travel details reflect the original guide; verify access rules, road conditions, and prices for a new trip.

## View locally

Requires Node.js 22 or newer:

```sh
npm ci
npm run dev
```

Open [localhost:4173](http://localhost:4173/).
