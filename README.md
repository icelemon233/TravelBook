# Cinna Travel

English | [简体中文](./README.zh-CN.md)

Road-trip guides with daily itineraries, route maps, budgets, notes, and checklists.

[Open the guides](https://icelemon233.github.io/cinna-travel/)

## Using a guide

Browse a day's plan or compare the available route variants. Driving references sit alongside the route maps. You can change budget and vehicle energy assumptions, add notes, mark checklist items, and print a copy.

Notes, budget settings, and checklist progress stay in the current browser and do not sync across devices. Recheck road conditions and other time-sensitive travel details before leaving; the maps and driving estimates are planning references.

## Local preview

With Node.js installed, run:

```sh
npm run dev
```

Open [localhost:4173](http://localhost:4173/). This version needs no additional packages.
