# Cinna Travel Archive

English | [简体中文](./README.zh-CN.md)

An earlier version of Cinna Travel, kept as a source reference for an interactive Tibet road-trip guide.

For the current project, visit [Cinna Travel](https://github.com/icelemon233/cinna-travel).

## Explore the guide

- Compare route options and browse daily plans.
- Review preparation steps, risks, and travel checklists.
- Adjust a travel budget and explore the route maps.
- View the guide on a phone or a larger screen.

Travel details reflect the guide's original context. Check current access rules, road conditions, and prices before using them for a new trip.

## Preview locally

Requires Node.js 22 or newer. From a clone of the repository:

```sh
npm ci
npm run dev
```

Open [localhost:4173](http://localhost:4173/).
