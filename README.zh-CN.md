# Cinna Travel

[English](./README.md) | 简体中文

自驾路书，包含每日行程、路线地图、预算、备注和准备清单。

[打开路书](https://icelemon233.github.io/cinna-travel/)

## 使用路书

按天查看安排，或对比已有的路线方案。路线地图附有驾驶参考。可以调整预算和车辆能耗假设，添加备注、勾选清单，也可以打印。

备注、预算设置和清单进度保存在当前浏览器，不会跨设备同步。路况及其他时效性信息需要在出发前重新核对，地图和驾驶估算用于规划参考。

## 本地预览

安装 Node.js 后运行：

```sh
npm run dev
```

打开 [localhost:4173](http://localhost:4173/)。当前版本无需安装额外依赖。
