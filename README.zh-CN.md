# Cinna Travel Archive

[English](./README.md) | 简体中文

Cinna Travel 的早期版本，保留一份交互式西藏自驾路书的源码，供查阅与参考。

当前项目请访问 [Cinna Travel](https://github.com/icelemon233/cinna-travel)。

## 可以查阅什么

- 对比路线方案，浏览每日安排。
- 查看准备步骤、风险提示和旅行清单。
- 调整旅行预算，查看路线地图。
- 在手机或较大屏幕上浏览路书。

旅行资料保留了编写时的背景。用于新的行程前，需要重新核对通行要求、路况与价格。

## 本地预览

需要 Node.js 22 或更新版本，克隆仓库后运行：

```sh
npm ci
npm run dev
```

打开 [localhost:4173](http://localhost:4173/)。
