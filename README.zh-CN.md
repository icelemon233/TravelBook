# Cinna Travel

[English](./README.md) | 简体中文

交互式自驾路书，把每日路线、地图、预算、备注和准备清单放在同一个页面中，方便出发前规划、路途中查阅。

[打开旅行路书](https://icelemon233.github.io/cinna-travel/)

## 规划与查阅

- 浏览每日行程，对比已有的路线方案。
- 结合每日安排查看路线地图与驾驶参考。
- 调整旅行预算和车辆能耗假设。
- 保存备注与准备清单，打印一份随身携带。

备注、预算设置和清单进度保存在当前浏览器，不会跨设备同步。地图和驾驶估算用于辅助规划，出行前仍需核对当时的实际情况。

## 本地预览

安装 Node.js，克隆仓库后运行：

```sh
npm run dev
```

打开 [localhost:4173](http://localhost:4173/)。当前版本不需要安装额外依赖。
