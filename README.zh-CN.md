# Cinna Travel Archive

[English](./README.md) | 简体中文

Cinna Travel 早期西藏自驾路书的源码。

[当前 Cinna Travel 项目](https://github.com/icelemon233/cinna-travel)

路书包含每日安排、路线方案、准备步骤、风险表格、预算和地图。资料保留编写时的背景，用于新行程前需核对通行要求、路况和价格。

## 本地查看

需要 Node.js 22 或更新版本：

```sh
npm ci
npm run dev
```

打开 [localhost:4173](http://localhost:4173/)。

## 资料来源

地图数据 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，遵循 ODbL；公路路线包含 OSRM 参考数据。部分风景和装饰图片为 AI 生成素材。
