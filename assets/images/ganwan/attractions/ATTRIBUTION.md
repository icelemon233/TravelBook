# 景点配图

六张照片来自 Wikimedia Commons，各自保留原作者和原授权。文件、作者、来源页面、授权链接和下载地址见 [`../../autumn/photo-sources.json`](../../autumn/photo-sources.json)，网页对应景点下方也显示署名与授权。

使用 Commons 提供的 960px 缩略图，网页通过 CSS 缩放与裁切显示；图片及其裁切版本按对应原许可提供，不改变整个网站代码的许可。历史照片仅供景观参考，不表示当前桥体、水位、季节或开放状态。

瑶里图片为当地山村景观参考，婺源图片对应清华彩虹桥；未使用它们冒充绕南、菊径、漳村或虹关的单独实景照片。
